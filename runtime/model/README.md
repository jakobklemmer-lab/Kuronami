Hierhin gehört die Modellanbindung: der Vertrag `ModelClient` (`types.ts`) und die eine Umsetzung darauf gegen die Claude API (`anthropic.ts`). `anthropic.ts` ist die einzige Datei im Projekt, die das Anbieter-SDK kennt; alles darüber sieht nur den Vertrag, deshalb kostet ein zweites Modell (Abschnitt 11, Modell-Routing) genau eine weitere Datei neben dieser. Der Client wird injiziert und nicht importiert — ein Loop, der fest an einem HTTP-Aufruf hängt, ist nicht prüfbar, weil er Geld kostet, Netz braucht und bei jedem Lauf anders antwortet; das Drehbuch-Modell für Tests steht in `../loop/scripted.ts`. Hier wird nichts entschieden und nichts protokolliert: welcher Prompt hinausgeht, bestimmt `context/`, was mit der Antwort geschieht, entscheidet `../loop/`.
