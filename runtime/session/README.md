Hierhin gehört der Lebenslauf einer Session: Anlegen und Wiederfinden nach einem Prozess-Neustart samt der Klammer um einen laufenden Runtime-Prozess (`manager.ts`), Wiederaufnahme und Abbruch (`lifecycle.ts`), Herleitung des Zustands aus dem Ereignisprotokoll (`state.ts`). Der Zustand liegt ausschließlich in der Datenbank, kein Cache im Prozessspeicher. Keine Schrittausführung — die gehört in die Ausführungshülle unter `steps/`.
