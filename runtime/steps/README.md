Hierhin gehört die Ausführungshülle: Checkpoint, Seiteneffekt, Checkpoint (`hull.ts`). Jeder externe Seiteneffekt läuft hierdurch, mit einem Idempotenzschlüssel je Schritt und einem Zeitfenster, das ein Hängen in einen `step.failed` verwandelt. Nur das Ausführen eines einzelnen Schritts, keine Schleife über Schritte und keine Entscheidung über offene Schritte — die trifft die Wiederaufnahme in `session/`.
