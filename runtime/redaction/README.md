Hierhin gehört der Redaction-Filter aus Abschnitt 4.7: eine Funktion, durch die jeder Schreibpfad läuft, der Text auf die Platte oder in den Modellkontext bringt (Ereignisprotokoll, Artefaktmetadaten, Prompt-Aufbau). `patterns.ts` trägt die erweiterbare Musterliste, `redact.ts` die Anwendung darauf, rekursiv über verschachtelte Werte. Bewusst nicht abschaltbar: es gibt kein Flag und keinen Parameter, mit dem sich der Filter umgehen ließe. Wer die Reichweite ändern will, ändert die Liste. Keine Freigabeentscheidungen und keine Risikostufen — die gehören in `policy/`; hier wird nichts entschieden, hier wird immer gefiltert.
