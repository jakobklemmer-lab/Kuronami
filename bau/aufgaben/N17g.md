## Regeln für jeden Kommentar

**Bleibt (gekürzt auf höchstens zwei Zeilen):** *warum* etwas so ist, wenn man es dem Code nicht
ansieht — eine Falle, eine Grenze, ein Messwert, der eine Zahl im Code begründet, ein Verweis auf
eine andere Datei, die man kennen muss.

**Fällt weg:** Datum („am 27.09.", „2026-09-20"), Sitzungsnummern (S36, N9), Zitate von Jakob,
Erzählung des Hergangs („ging schief, weil … dann haben wir …"), Wiederholung dessen, was der Code
ohnehin sagt, Verweise auf Entferntes (n8n, alter Motor, Mock-Daten, Slack).

**JSDoc an exportierten Funktionen:** ein Satz, was sie tut, plus Fallen. Keine Absätze.

**Nie anfassen:** Code; Zeichenketten (auch Prompt-Texte in Backticks — das sind Strings, keine
Kommentare); Direktiven wie `// biome-ignore …`, `// @ts-expect-error`, `// @ts-ignore`,
`/* eslint … */`; eine Shebang-Zeile. Nichts übersetzen, nichts umbenennen.

**Beispiel 1** — vorher:
```ts
  /**
   * Nachtrag 2026-09-16: die Oberfläche liest hier direkt, ohne den Agenten-Loop zu bemühen —
   * dieselbe Haltung wie beim Trading-Chart (direkter Abruf, kein Modellaufruf). `mail.search`
   * als Werkzeug bleibt für den Assistenten daneben bestehen (Artefakt, Redaction, Kontext-
   * Kürzung); dieser Rand hier ist nur die Kurzfassung fürs Dashboard.
   */
```
nachher:
```ts
  /** Die Post für die Oberfläche, direkt über IMAP (`postfach.ts`) — ohne Modellaufruf. */
```

**Beispiel 2** — vorher:
```ts
    // Ein Schichtungstest, der versehentlich null Dateien liest, ist immer grün. Deshalb steht
    // die Zahl hier fest genug, um das zu bemerken, und offen genug, um nicht bei jeder neuen
    // Datei zu reißen. Bis 2026-09-20 waren es über 50 Dateien; nach dem Ausbau des alten
    // Motors sind 44 übrig, und die Schwelle rutscht mit.
```
nachher:
```ts
    // Ein Schichtungstest, der versehentlich null Dateien liest, ist immer grün. Die Schwelle
    // soll ein leeres Verzeichnis melden, nicht eine Aufräumarbeit.
```

**Beispiel 3** — ein Kommentar, der nur den Code nacherzählt, fällt ganz weg:
```ts
    // Den Zähler um eins erhöhen.
    zaehler += 1;
```
→ nur noch `zaehler += 1;`
